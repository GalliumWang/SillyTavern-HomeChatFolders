# 首页会话文件夹 · v0.3.0

一个独立的 SillyTavern 前端扩展：把进入酒馆时首页中间的默认会话列表替换成可使用文件夹分类的会话界面。面向官方 **SillyTavern 1.19.0**，支持反向代理子路径部署（如 `/sillytavern/`），不需要服务器插件、Extras、新 API 服务或构建步骤。

## 安装

### 使用仓库 URL 安装（推荐）

1. 打开酒馆 → 扩展程序 → 安装扩展程序。
2. 粘贴仓库地址：

   ```text
   https://github.com/GalliumWang/SillyTavern-HomeChatFolders
   ```

3. 安装完成后刷新页面，关闭当前聊天返回首页。
4. 在“管理扩展”中确认“首页会话文件夹”已启用。

以后可以在“管理扩展”中检查和更新本扩展。无需开启服务器插件，也不需要在服务器执行额外安装命令。

### 本地文件安装

1. 解压 `SillyTavern-HomeChatFolders-v0.3.0.zip`。
2. 把其中的整个 `SillyTavern-HomeChatFolders` 文件夹放到你实际运行的酒馆目录：

   ```text
   SillyTavern/
   └─ public/
      └─ scripts/
         └─ extensions/
            └─ third-party/
               └─ SillyTavern-HomeChatFolders/
                  ├─ manifest.json
                  ├─ index.js
                  ├─ style.css
                  └─ src/
   ```

3. 在浏览器强制刷新酒馆页面（Windows：`Ctrl + F5`），关闭当前聊天以回到首页。
4. 在“管理扩展”确认“首页会话文件夹”处于启用状态。首页原列表会被“我的会话”接替。

不要多套一层同名文件夹：`manifest.json` 必须直接位于上面指定的扩展目录内。Docker 或远程部署需要把文件放到正在提供酒馆页面的那一份实例中；仅放到浏览器所在电脑不会生效。不需要修改 `config.yaml` 或启用 `enableServerPlugins`。

本地手动安装位置对实例内所有账户提供扩展代码；具体分类数据保存在各账户自己的扩展设置中。

## 使用

- **多角色与群聊手动归档**：默认提供“全部会话”“未分类”，以及可自由编辑的“进行中”“已完结”“暂时搁置”。同一文件夹可以放不同角色和不同群组的聊天，不做自动归类。
- **默认直属会话与子文件夹开关**：点击父文件夹默认只展示直属会话；面包屑右侧提供轻量的 `包含子文件夹` 勾选开关（默认关闭），勾选后可一并浏览所有下级子文件夹会话。左侧文件夹徽标计数随该开关及搜索词实时同步。
- **新建与整理文件夹**：点击“＋ 新建文件夹”；当前位于用户文件夹时默认作为其子文件夹。文件夹右侧 `⋯` 可修改名称、父级、颜色和同级顺序（切换父级下拉框时可实时预览并调整新父级下的排序），同级禁止重名。删除文件夹不会删除任何聊天：直属会话回到“未分类”，子文件夹自动提升一级（重名自动追加序号）。
- **平铺快捷操作按钮**：每条会话右侧直接平铺展示 `☆ 置顶 / ★ 已置顶`、`移入`、`改名`、`删除` 四个按钮（窄屏自动换行置于标题下方，不挤压长标题，也不把删除藏进二级菜单）：
  - **星标置顶（原生互通）**：直接读写酒馆 `accountStorage` 的原生 `'pinnedChats'` 数据，置顶会话在当前视图始终优先排在顶部，切换回原生首页依然保持一致。
  - **首页行内改名**：无需先进入聊天，点击“改名”即可直接调用酒馆重命名接口并确认 `CHAT_RENAMED` 事件，自动解析服务端清洗后的真实文件名，文件夹归属与星标置顶无缝跟随。
  - **移入与拖拽**：点击“移入”或勾选后批量“移动到…”，桌面端也可拖拽单条或多选会话到左侧文件夹。
  - **安全删除**：单条“删除”或跨页批量“删除所选”均需明确弹窗确认，展示数量与会话名。此操作调用酒馆原生删除功能永久移除聊天文件，无法通过分类备份恢复，请提前备份重要聊天。
- **高效多选与搜索排序**：勾选框支持 `Shift + 点击` 连续区间多选（局部更新勾选状态，不触发整表重建）。“选本页”只选当前页 50 条，支持跨页保留选择；搜索支持多关键词同时匹配（带输入法组合保护与防抖），可按最近消息、最早消息、会话名或角色名排序。
- **预览模式**：“显示预览”展示酒馆已有的最后消息摘要，默认关闭。所有名称与预览均以安全纯文本渲染。

## 保存、增量合并导入与快照回滚

分类数据保存在 `extensionSettings.home_chat_folders`，通过酒馆原有的设置保存机制提交；当前选中的文件夹与折叠展开等纯浏览态保存在本地 `accountStorage`（`hcf_view_state`），日常切换文件夹不会频繁触发服务端设置写入。

- **导出备份**：导出 JSON 包含文件夹树、会话归属和偏好设置，不包含聊天正文。
- **合并导入与全量替换**：导入备份文件（自动兼容 UTF-8 BOM，限制 8 MB、最多 1000 个文件夹、50000 条归属、最多 12 层嵌套）时弹窗提供两种模式：
  - **合并导入（推荐）**：保留现有分类，按规范化文件夹路径自动复用或新建缺失文件夹，仅补充尚未归类的会话，绝不覆盖已有归属。
  - **全量替换**：用备份完整替换当前文件夹与分类（保留当前插件启用状态）。
- **自动回滚快照**：每次执行导入或删除文件夹前，自动在本地 `accountStorage`（`hcf_snapshots`）滚动保留最近 **3 份**完整快照。首页顶部和扩展设置面板均提供“撤销上次导入/删除”一键恢复。
- **容错软恢复**：启动时若检测到历史配置存在异常字段、孤立引用或同级重名，插件会自动隔离脏条目并正常启动，同时将原始配置备份至 `accountStorage`（`hcf_corrupt_backup`），不会锁死界面或设置入口。

## 失联记录批量治理与自动清理

监听酒馆的会话重命名（`CHAT_RENAMED`，兼容 1.19.0 未清洗文件名及 `.jsonl.jsonl` 双扩展名场景）与角色改名（`CHARACTER_RENAMED`，冲突时保留原条目不回滚其他正常迁移）事件。

若在服务器文件管理器直接改名、删除角色卡或外部工具改动聊天文件，完整目录加载后状态栏右侧始终显示“待关联”（即使当前存在错误横幅也可随时点击打开）：

- **批量治理弹窗**：支持复选框多选批量移除失联分类、“一键清理角色/群组已不存在记录”，以及将单条分类重新关联到改名后的会话（下拉列表优先置顶同一角色/群组下的未分类会话，支持关键词筛选，操作后弹窗保持开启以便连续处理）。
- **可选联动清理**：在“扩展设置 → 首页会话文件夹”中可勾选 `在酒馆内删除会话或角色时自动移除对应文件夹归属`，开启后在酒馆原生界面删除单聊、群聊或角色卡时会自动同步移除对应分类与置顶记录。

## 恢复默认首页与生命周期

首页点击“恢复原列表”即停用首页替换，分类数据保留；重新启用入口位于酒馆扩展设置中的“首页会话文件夹 → 启用首页文件夹”。

在“管理扩展”中停用、重新启用或清理扩展数据时，通过 `manifest.json` 生命周期钩子（`activate`、`enable`、`disable`、`delete`、`clean`）自动完成监听挂载、卸载与存储清理，无需手动刷新页面。

## 加载策略与已知限制

- 首次进入首页先读取最近 60 个会话快速首屏呈现，随后后台补全完整历史目录；从聊天返回首页时采用缓存直出 + 后台静默校验（Stale-While-Revalidate），点击“刷新目录”会同步刷新酒馆内存角色与群组列表（`getCharacters`）。
- 兼容基线为官方 SillyTavern 1.19.0；建议同时只启用一个替换首页会话列表的扩展。
- 酒馆原生 `/api/chats/recent` 接口在全量扫描时仍需读取磁盘聊天元数据，超大量会话首次扫描可能耗时，超时上限为 180 秒，失败后保留已有数据并可重试。
- 只展示仍有关联角色或群组的常规会话；无主孤立文件会跳过并在状态栏提示数量。

## 开发与打包验证

运行时无需任何 npm 依赖。使用 Node.js 自带语法检查与测试工具：

```shell
npm run check
npm test
```

本地模拟预览环境：

```shell
node tests/preview-server.mjs
```

浏览器打开 `http://127.0.0.1:18791/` 即可在独立模拟酒馆环境中验证全部交互（含子文件夹计数、平铺按钮、星标置顶、行内改名、合并导入、快照撤销与失联批量治理）。测试与脚本文件不会打入发布包。

打包发布 ZIP（PowerShell，默认输出 `dist/SillyTavern-HomeChatFolders-v0.3.0.zip`，内置防覆盖校验）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package.ps1
```

也可使用跨平台 Python 3 标准库脚本打包：

```shell
python scripts/package.py
```
