# 首页会话文件夹 · v0.1.0

一个独立的 SillyTavern 前端扩展：把进入酒馆时首页中间的默认会话列表替换成可使用文件夹分类的会话界面。面向官方 **SillyTavern 1.19.0**，不需要服务器插件、Extras、新 API 服务或构建步骤。

## 安装

### 使用仓库 URL 安装（推荐）

1. 打开酒馆 → 扩展程序 → 安装扩展程序。
2. 粘贴仓库地址：

   ```text
   https://github.com/GalliumWang/SillyTavern-HomeChatFolders
   ```

3. 安装完成后刷新页面，关闭当前聊天返回首页。
4. 在“管理扩展”中确认“首页会话文件夹”已启用。

以后可以在“管理扩展”中检查和更新本扩展。无需开启服务器插件，也不需要在服务器执行额外安装命令。

### 本地文件安装

1. 解压 `SillyTavern-HomeChatFolders-v0.1.0.zip`。
2. 把其中的整个 `SillyTavern-HomeChatFolders` 文件夹放到你实际运行的酒馆目录：

   ```text
   SillyTavern/
   └─ public/
      └─ scripts/
         └─ extensions/
            └─ third-party/
               └─ SillyTavern-HomeChatFolders/
                  ├─ manifest.json
                  ├─ index.js
                  ├─ style.css
                  └─ src/
   ```

3. 在浏览器强制刷新酒馆页面（Windows：`Ctrl + F5`），关闭当前聊天以回到首页。
4. 在“管理扩展”确认“首页会话文件夹”处于启用状态。首页原列表会被“我的会话”接替。

不要多套一层同名文件夹：`manifest.json` 必须直接位于上面指定的扩展目录内。Docker 或远程部署需要把文件放到正在提供酒馆页面的那一份实例中；仅放到浏览器所在电脑不会生效。不需要修改 `config.yaml` 或启用 `enableServerPlugins`。

本地手动安装位置对实例内所有账户提供扩展代码；具体分类数据保存在各账户自己的扩展设置中。

## 使用

- 默认有“全部会话”“未分类”，以及可编辑的“进行中”“已完结”“暂时搁置”。同一文件夹可以放不同角色和不同群组的聊天。
- 点击“新建文件夹”。当前位于用户文件夹时，新文件夹默认成为它的子文件夹；也可以改成顶层或其他父级。
- 勾选会话后点击“移动到…”，或点击单条右侧“移入”。桌面端也可把会话拖到左侧文件夹；选中多条后拖动其中一条可批量移动。
- “选本页”只选当前 50 条。支持跨页保留选择；切换文件夹或搜索时清空选择，避免误移动隐藏的搜索结果。
- 文件夹右侧 `⋯` 可修改名称、父级、颜色和同级顺序。点击箭头收起或展开子文件夹。
- 文件夹显示自己的直属会话；子文件夹的会话需要点击子文件夹查看。计数也按直属会话计算。
- 删除文件夹不会删除聊天：直属会话回到“未分类”，子文件夹提升一级。此版本不提供永久删除聊天的功能。
- 搜索匹配角色/群组名称与会话名称，多个关键词按同时匹配处理；不做聊天全文搜索。可按最近消息、最早消息、会话名或角色名排序。
- 点击会话名称打开对应聊天；打开过程中暂时禁用其他会话按钮。
- “显示预览”展示酒馆已有的最后消息摘要，默认关闭。名称和预览始终作为纯文本显示。

## 保存、导出和恢复

分类使用 `extensionSettings.home_chat_folders`，通过酒馆原有的设置保存机制提交。文件夹操作不会改写或搬动聊天 JSONL 文件。

刷新页面会重新读取账户设置。同一账户、同一套酒馆数据在另一设备重新加载后也可读取已保存分类；不提供多设备实时协同，同时在多个设备或标签页编辑仍可能覆盖设置。插件会拒绝它能检测到的过期修改。请使用“导出”保存独立分类备份。

导出 JSON 包含文件夹、归属和显示偏好，不包含聊天正文，也不能代替聊天备份。导入会校验格式并明确确认后替换现有分类，保持当前的启用状态。单个导入文件限 8 MB，最多 1000 个文件夹、50000 条归属，嵌套最多 12 层。

界面与分类偏好由酒馆的防抖保存机制持久化；页面不是独立实时数据库。服务器断开时无法保证设置已落盘，使用中应等待酒馆正常完成设置保存后再关闭页面。

## 恢复默认首页

首页点击“恢复原列表”即停用首页替换。重新启用入口在酒馆扩展设置中的“首页会话文件夹 → 启用首页文件夹”。分类会保留。

在“管理扩展”停用本扩展，也会清理监听并恢复原生列表。必要时刷新页面。卸载扩展文件不会移动或删除聊天；分类属于酒馆的账户设置。

## 加载和重命名

第一次先读取最近 60 个会话，再补全历史目录。页面显示加载状态，失败后保留已读取会话及所有分类，可点“刷新目录”重试。返回首页时会根据聊天事件决定是否刷新；移动文件夹不会再次扫描全部聊天。

监听酒馆的会话及角色重命名事件，迁移已有分类。分支和新会话默认归入“未分类”，本版不推断父会话归属。

在服务器文件管理器中直接改名、其他扩展未发出原生事件或原生文件名清洗差异，可能产生失联记录。完整目录成功加载后，状态栏会显示“待关联”，可以手动选择新会话重新关联，或仅移除失联分类。扫描不完整时不会把未加载的旧会话判定为失联。

## 已知限制和测试范围

- 兼容基线为官方 1.19.0。没有承诺旧版、第三方魔改版或所有美化插件均兼容。
- 与其他直接替换首页的扩展可能冲突，建议同时只启用一个首页替换扩展。
- 酒馆原生接口仍会扫描磁盘及聊天正文。纯前端分页仅减少 DOM 数量，不能消除首次全量扫描成本；大量超长聊天可能需要较长时间。请求最多等待 180 秒，超时可重试。
- 只展示仍有关联角色或群组的常规聊天。孤立文件和无角色的特殊聊天会跳过，并在状态栏提示数量。
- 已通过内置自动测试和 Chrome 模拟环境的界面验证。模拟环境覆盖了 137 个会话；尚未把本扩展装到用户真实酒馆实例进行集成测试，也未更改用户的聊天或服务端配置。

## 开发与验证

运行时无需任何 npm 依赖。使用 Node.js 自带测试工具：

```shell
npm run check
npm test
```

本地界面验证：

```shell
node tests/preview-server.mjs
```

浏览器打开 `http://127.0.0.1:18791/`。这里只是模拟酒馆接口的开发测试页；它使用独立的浏览器存储，不连接真实酒馆，提供模拟错误等验证入口。测试文件不进入插件 ZIP。

打包（Python 3 标准库）：

```shell
python scripts/package.py
```
